# frontend/CLAUDE.md

Rules for the dashboard. The root `CLAUDE.md` still applies.

## Stack and commands

React 19, TypeScript (strict), Vite, Tailwind v4, Vitest + Testing Library, oxlint, Prettier.
From `frontend/`: `npm run dev`, `npm test` (with coverage), `npm run typecheck`,
`npm run lint`, `npm run format`. From the root, `make check` runs all of them.

## Rules

- API types come from the backend: `import type { components } from './api/schema'`, then
  `components['schemas']['Name']`. Never hand-write a type for an API response.
  `src/api/openapi.json` and `src/api/schema.d.ts` are generated by `make api-types`; don't
  edit them (ADR-0017).
- The dashboard is read-only for shared viewers: no measurements or photos in any view a share
  link can reach (root security rules).
- Coverage floor is 80% for lines, branches, functions and statements. Test behaviour the user
  sees (Testing Library queries by role and text), including loading and error states.
- Mock `fetch` in tests; never call a real server.
- Styling is Tailwind utility classes. No new CSS files or component libraries without an ADR.
